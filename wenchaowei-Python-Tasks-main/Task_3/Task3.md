## 编程题##

1. 任意输入一个字符串，提取其中不重复的英文（按小写处理）和数字并输出。

   *提示: 可使用str.isalnum()函数判断是否为英文或数字。*

   ~~~
   实例输入
   321786472137216387126 *(@*#*!&@(*#&@*(! yufyeuiqr eAJDHKJSAHDK

   输出
   3217864yufeiqrajdhks
   ~~~

2. 输入种子数x与整数n，两者以空格分割，构建大小为n*n的随机方阵，输出该方阵与其转置矩阵。

   *提示：要使用random（）函数*

   ~~~
   示例输入
   1 5

   示例输出
   [[17, 72, 97, 8, 32], [15, 63, 97, 57, 60], [83, 48, 100, 26, 12], [62, 3, 49, 55, 77], [97, 98, 0, 89, 57]]
   [[17, 15, 83, 62, 97], [72, 63, 48, 3, 98], [97, 97, 100, 49, 0], [8, 57, 26, 55, 89], [32, 60, 12, 77, 57]]
   ~~~
